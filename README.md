# ANKITA SINGH — Portfolio

Personal developer and data analyst portfolio built in a "Signal HUD" aesthetic with motion-led technical interfaces and an interactive 3D signal core.

Built during the placement training program at [TAP Academy](https://thetapacademy.com/) (full-stack development, AI and augmented reality training).

## Live Site
- **URL:** [https://YOUR-SITE-URL/](https://YOUR-SITE-URL/)

## Tech Stack
- **Framework & Runtime:** React 19, Vite
- **Styling:** Tailwind CSS 4
- **Animation & Motion:** GSAP (with ScrollTrigger), Lenis (smooth scroll)
- **3D Graphics:** Three.js
- **Services:** EmailJS (`@emailjs/browser`)

## Run Locally

Install project dependencies:

```bash
npm install
```

Start the development server:

```bash
npm run dev
```

Build for production:

```bash
npm run build
```

## Environment Variables

Create a `.env.local` file in the project root with your EmailJS credentials:

```env
VITE_EMAILJS_SERVICE_ID=
VITE_EMAILJS_TEMPLATE_ID=
VITE_EMAILJS_PUBLIC_KEY=
```
